# 简介

`@inventory-table/vue` 是一个面向库存 / 仓储场景的 Vue 3 表格组件，基于 [Element Plus](https://element-plus.org/) 构建。

## 特性

- `<script setup>` + TypeScript，props / emits / mock 文件级抽离
- 搜索、分类 / 仓库 / 状态筛选、分页、多选、行内改数量
- 自动计算库存状态：充足 / 偏低 / 缺货
- 支持客户端过滤与服务端分页两种模式
- `useMock` 一键启用演示数据，方便文档与本地调试
